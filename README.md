# Minecraft Sounds Buttons (MSB)

Java android studio project for listening to Minecraft music and sounds

## Dependencies
1. [ Monocraft ](https://github.com/IdreesInc/Monocraft)
2. Minecraft official soundtraks

## Requirements

1. Android
2. version upper Tiramissu
